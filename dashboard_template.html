What each part of the circuit does

 

  
Activation vector (VECTOR REG)The current guess v for the orbital: one number per atom. PWM duty cannot be negative, so the controller splits v into a positive part v⁺ and a negative part v⁻ and runs them as two separate passes.

  
PWM timersTurn each number into a duty cycle: a 255-clock square wave that is high for D clocks. Larger |v| gives a wider pulse (the small waveform under each timer shows it). One timer group per 4-input tile.

  
Weight shift registers and DACThe Hückel adjacency matrix A (1 = bonded atoms) is stored as 8-bit codes, loaded 32 bits at a time per tile, MSB first. A DAC turns each code into a fixed voltage.

  
Analog cell array (switches)Each cell is a switch that connects its DAC voltage to the wire only while its PWM is high. Averaged over time that gives voltage × duty = weight × activation, so one cell is one multiplier. The lever closes when the cell is conducting.

  
Σ summing node and RC filterFour cells share one node through resistors and a capacitor. The node adds their products and smooths out the PWM ripple. It needs about 8 time constants (≈2 ms) to settle, which sets the speed of the whole machine.

  
ADCDigitises each tile's node voltage into a signed code. Quantisation and read noise enter here.

  
Accumulate (outputs)Digital adders sum a row's tile codes into one output yr = Σ Arj·vj. All rows together are one matrix-vector product.

  
Digital controllerCombines y⁺ − y⁻, adds the shift s·v digitally, removes orbitals already found (Gram-Schmidt), normalises, and checks whether the vector has stopped changing (Δ below the tolerance). The result feeds back as the next v.

 


 
What the side panels show

 

  
Stage stripThe chips above the circuit show which of the eight stages is active right now. Moving dashes on a wire mean that wire is carrying signal in that stage.

  
MoleculeEach carbon carries one amplitude of the current orbital estimate. Blue = positive, red = negative, size = |amplitude|. A green bond means the two neighbours are in phase (bonding); a red dashed bond means out of phase. More out-of-phase bonds means a higher-energy orbital.

  
Finished orbitalsA thumbnail of each converged orbital with its analog x. Each holds two electrons (↑↓).

  
π levelsEnergy ladder in units of |β|. Dashed = exact level, green = level found by the analog machine. Energy is α + xβ with β negative, so larger x means lower energy.

  
Convergencelog10 of how far the vector moved in each iteration. The orbital is finished when it falls below the dashed tolerance line.

 


 
How to read the numbers

 

  
Analog x vs refined xAnalog x is the eigenvalue estimate read from the analog passes, so it carries gain mismatch, ADC and noise error. Refined x recomputes the Rayleigh quotient digitally on the same final vector. It stays accurate (about 1e-4) even when the analog value is off, which shows the vector itself is good.

  
Shift sThe array holds A. The digital side adds s·v so the iteration converges on the occupied (largest) orbitals. Doing this digitally, not in the array, cut the benzene error about 2.8×.

  
What this is notA classical hybrid analog-digital simulation of a toy Hamiltonian, not quantum hardware and not chemical accuracy. Offset and noise sizes are placeholders; only the 1.7 % gain mismatch comes from the paper. Python models every row and tile as a parallel analog node, while the Verilog FSM drives one tile at a time.

BufferRail-to-rail op-amp followerThe node impedance is about 2.5 kΩ, which is high for an ADC input. The buffer adds its own offset

Build order

 

  
1. Analog benchBreadboard one tile: DAC, switches, 4 × Rf, Cf. Drive the switches from the FPGA with the existing mac_ctrl PWM. Check the settled node voltage against your SPICE result (about 0.27 V for your test weights).

  
2. Read itAdd an XADC wrapper and a UART. Confirm that pass A and pass B differ by the predicted amount, and that the read repeats to a few LSB.

  
3. Close the loopRun mac_fsm jobs from the PC for one matvec, then a full benzene run. Compare the energy error to the Python error budget.

  
4. Scale upOnly after 1–3 work: several tiles in parallel, a PCB, or a SKY130 version.

 


 
Things that will bite

 

  
Switch dead timeThe netlist drives S1 and S2 with ideal complementary pulses. Real switches can overlap for a few ns and short the DAC to ground through two Ron. The FPGA must generate a gap between PWM and its complement. mac_ctrl.v has none today.

  
DAC update path is newmac_fsm exposes weights_dac (32 bits) but nothing yet turns it into I²C or SPI traffic. That driver is new Verilog and needs its own testbench.

  
Placeholders become realOffset and noise in the model are guesses. On hardware they are measured: switch charge injection, buffer offset, XADC noise. The first bench result replaces them.

  
Repeated readsThe FSM reads in consecutive PWM periods, about 10 µs apart on a 252 µs filter, so the noise samples are probably correlated. Averaging helps less on hardware than the model assumes.

  
ClockRun the design from 25 MHz (10.2 µs PWM period, 198 settle periods) as the handoff proposes. At 100 MHz you need 791 settle periods.
